# От чата к своему AI-помощнику

Публичная русскоязычная статья о практическом использовании AI-агентов: для руководителя IT-компании, повседневных задач и команды.

**Страница:** https://rival.github.io/agent-field-guide/

## Что внутри

- Бытовые сценарии: файлы, фотографии, роутер, диагностика компьютера, осторожная работа с повреждённым носителем.
- Разница между моделью, чатом и агентским окружением; Claude Code, Codex, Pi.
- Независимость от поставщика, переносимость проектов и ограничения подписок.
- Расширения Pi, мобильные устройства, экспериментальный DeepSeek Harness.
- Навыки, Superpowers, SDD и уточнение требований до реализации.
- Herdr, Hermes, OpenClaw, память, мессенджеры и внутренний помощник компании.
- Компьютер или VPS, сетевые риски, права доступа и защита данных.

## Устройство

Статическая страница без сборки, бэкенда, JavaScript, аналитики или внешних ресурсов во время чтения. HTML, CSS и локальные файлы шрифта. Обычные внешние ссылки открываются только по действию читателя.

- `index.html` — содержание, схемы и ссылки на первоисточники.
- `styles.css` — адаптивный макет и стили печати.
- `assets/` — значок и локальный Golos Text.
- `tests/site.spec.js` — браузерные проверки содержания, навигации, адаптивности и доступности.
- `docs/plans/` — публичный план реализации, без внутренней инфраструктуры.

Golos Text используется по SIL Open Font License; лицензия — `assets/fonts/OFL.txt`. Исходные файлы получены из Google Fonts, запросов к нему при чтении нет.

## Локальный просмотр

Нужен Python 3:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173/.

## Проверки

Для тестов дополнительно нужны поддерживаемый Node.js LTS и npm:

```sh
npm ci
npx playwright install chromium --only-shell
npm test
```

Playwright сам запускает локальный сервер. На некоторых Linux-системах могут потребоваться системные зависимости браузера. Проверяются ширины 360, 390, 768 и 1440 пикселей, клавиатурная навигация, фрагментные ссылки, загрузка ресурсов, отсутствие сторонних сетевых запросов и серьёзных нарушений WCAG, обнаруживаемых axe. Автоматические проверки не заменяют ручной просмотр.

Проверка опубликованной версии:

```sh
SITE_URL=https://rival.github.io/agent-field-guide/ npm test
```

## Публикация

GitHub Pages обслуживает корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll. Развёртывание не требует секретов, сервера приложений или облачных API-ключей.

## Редакционные ограничения

Не добавлять адреса машин, ключи, клиентские данные или внутренние конфигурации. Проверять условия подписок и возможности интеграций по первоисточникам при обновлении. Не выдавать техническую возможность входа за разрешение поставщика, память агента — за обучение весов, а сценарий интеграции — за уже встроенную функцию.
